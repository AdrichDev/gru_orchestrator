# Acceptance Criteria: Agent Wizard Widget Configuration

- [ ] Sectors are global, paginated by 9, alphabetically sorted, and include `Otro`.
- [ ] Selecting `Otro` reveals `Introduce el Sector`, with disabled/enabled add button and success/error states.
- [ ] Sidebar icons come from a typed reusable source.
- [ ] Wizard steps are split into reusable components/hooks.
- [ ] Prompt step auto-fills a complete sector-specific prompt and AI improvement expands it.
- [ ] Skills step filters by name/category and selects marketplace skills.
- [ ] Agent widget config persists colors, Base64 avatar, emoji fallback, and template JSON.
- [ ] Widget displays configured avatar and real agent name.
- [ ] Knowledge duplicate ingestion asks for confirmation and supports overwrite/suffix.
- [ ] Chatbot lead capture stores a structured `Lead`.
- [ ] Backend tests, frontend typecheck, backend typecheck, and frontend build pass.
